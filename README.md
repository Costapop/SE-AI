# SE-AI — дефекты тонкой плёнки по остатку эллипсометрического фита

Одностраничное веб-приложение (все вычисления в браузере), которое по спектру Ψ(λ), Δ(λ) и априорной информации об образце находит наиболее вероятный набор дефектов тонкой плёнки и выполняет окончательный фит в выбранной модели.

**Схема:** опорный фит однородной плёнки → остаток фита как «отпечаток пальца» → ИИ-модель, обученная на остатках, смоделированных для тех же условий → вероятности наборов дефектов → окончательный фит в выбранной модели → сверка со скрытой истиной и разбор причин отклонения (для симулированных образцов).

Дефекты: **неоднородность показателя преломления по глубине** (линейный градиент любого знака) и **шероховатость поверхности** (слой Бруггемана). Задняя сторона подложки не учитывается (подложка полубесконечная).

Методическая основа — статистический шаг ограничен выбором модели из короткого списка, параметры внутри модели определяет физика: К. Попов, *AI-assisted model discovery in spectroscopic ellipsometry* (рукопись, 2026); о единственности восстановления в этом классе моделей — K. Popov, Phys. Scr. **101** (2026) 295206.

*English summary.* A single-page browser app that (1) fits a homogeneous-film model to a measured spectroscopic-ellipsometry spectrum, (2) trains a multinomial logistic regression on fit residuals simulated for the same measurement conditions (six classes: no defect, index gradient of either sign, surface roughness, and their combinations), (3) reports class probabilities for the measured residual, and (4) performs the final fit in the selected model. A measurement simulator with realistic instrument effects and five ready-made test spectra (with an answer key) are included.

## 1. Быстрый старт

1. Откройте `index.html` в браузере (двойным щелчком или через любой статический сервер, например `python3 -m http.server`). Если для репозитория включён GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root), приложение доступно по адресу https://costapop.github.io/SE-AI/ без установки. Нужен доступ в интернет для загрузки Chart.js, SheetJS и шрифта с CDN; сами вычисления идут локально.
2. В панели «Спектр» уже выбран первый тестовый образец (TiO₂ на BK7, 65°). Нажмите **«Выполнить все шаги»**.
3. Через 1–3 минуты (обучение ИИ) внизу появятся: окончательный фит, сверка со скрытой истиной образца и разбор причин отклонения.
4. Чтобы проверить свой спектр — загрузите файл `.xlsx`/`.csv` (формат в [разделе 7](#7-форматы-файлов)), задайте материал, подложку, угол и номинальную толщину и снова нажмите «Выполнить все шаги».
5. Чтобы проверить алгоритм на произвольной комбинации дефектов — задайте её в панели «Симулятор измерения» и нажмите **«Сгенерировать измерение»**: спектр станет текущим, истина будет скрыта до шага 4.

Шаги можно запускать и по отдельности (кнопки 1–4). Перед каждым запуском шага панели этого и всех нижестоящих шагов очищаются.

## 3. Физическая модель

### 3.1. Конвенции

* Комплексный показатель $N = n - ik$, фазовый множитель $e^{-2i\beta}$, временной множитель $e^{+i\omega t}$ (Аззам–Башара; так же считают приборы).
* $\rho = r_p / r_s = \tan\Psi\, e^{i\Delta}$, $\Delta \in [0°, 360°)$.
* Угол падения $\varphi_0$ задаётся в градусах; $\cos\theta_j = \sqrt{1 - (\sin\varphi_0 / N_j)^2}$ с главной ветвью корня.

### 3.2. Отражение от стопки слоёв

Коэффициенты Френеля на границе $i \to j$:

$$r_p = \frac{N_j \cos\theta_i - N_i \cos\theta_j}{N_j \cos\theta_i + N_i \cos\theta_j},\qquad r_s = \frac{N_i \cos\theta_i - N_j \cos\theta_j}{N_i \cos\theta_i + N_j \cos\theta_j}.$$

Рекурсия Эйри снизу вверх для каждого слоя $j$ толщины $d_j$:

$$r \leftarrow \frac{r_{\text{верх}} + r\, X_j}{1 + r_{\text{верх}}\, r\, X_j},\qquad X_j = e^{-2i\beta_j},\quad \beta_j = \frac{2\pi d_j}{\lambda} N_j \cos\theta_j .$$

Из $r_p$, $r_s$ вычисляются Ψ, Δ, а также нормированные элементы матрицы Мюллера

$$\mathcal N = \frac{|r_s|^2 - |r_p|^2}{|r_p|^2 + |r_s|^2},\quad \mathcal C = \frac{2\,\mathrm{Re}(r_p r_s^*)}{|r_p|^2 + |r_s|^2},\quad \mathcal S = \frac{2\,\mathrm{Im}(r_p r_s^*)}{|r_p|^2 + |r_s|^2},$$

через которые выполняется свёртка со спектральной полосой (усредняются именно $\mathcal N, \mathcal C, \mathcal S$, а не углы): $\Psi = \tfrac12 \arccos\mathcal N$, $\Delta = \operatorname{atan2}(\mathcal S, \mathcal C)$.

### 3.3. Дисперсия плёнки: Тауц–Лоренц + УФ-полюс

Физически допустимая (причинная, согласованная с преобразованием Крамерса–Кронига) модель диэлектрической функции $\varepsilon = \varepsilon_1 + i\varepsilon_2$:

$$\varepsilon_2(E) = \begin{cases} \dfrac{A E_0 C (E - E_g)^2}{\left[(E^2 - E_0^2)^2 + C^2 E^2\right] E}, & E > E_g \\ 0, & E \le E_g \end{cases}$$

$\varepsilon_1(E)$ — аналитическое КК-выражение Джеллисона–Модина (1996, с исправлением опечаток), плюс полюс Зельмейера для переходов выше измеряемого диапазона и $\varepsilon_\infty = 1$:

$$\varepsilon_1(E) = 1 + \varepsilon_1^{TL}(E) + \frac{A_{uv}}{E_{uv}^2 - E^2}.$$

Параметры: $A$, $E_0$, $C$, $E_g$ (эВ), $A_{uv}$ (эВ²), $E_{uv}$ (эВ). В фите свободны $A$, $A_{uv}$, $E_g$; $E_0$, $C$, $E_{uv}$ фиксируются справочными значениями (иначе при видимом диапазоне и прозрачной плёнке они не определяются). $N = \sqrt{\varepsilon}$, $k \ge 0$.

Справочник (`MATERIALS` в ядре) — типовые значения для аморфных плёнок, подобранные так, чтобы $n$ при 400/550/800 нм соответствовал литературным диапазонам:

|---|---|---|---|---|---|---|---|---|
| tio2 | TiO₂ (аморфный) | 255.83 | 4.00 | 1.77 | 3.40 | 137.65 | 11.0 | 2.270 |

### 3.4. Подложки (полубесконечные)

| ключ | подложка | модель |
|---|---|---|
| bk7 | стекло BK7 | формула Зельмейера Schott N-BK7, k = 0 |
| silica | плавленый кварц | Зельмейер Malitson (1965), k = 0 |
| si | кремний c-Si | таблица n, k (400–1000 нм, по Aspnes–Studna 1983) с линейной интерполяцией |
| glass152 | стекло n = 1.52 | без дисперсии, k = 0 |

### 3.5. Дефекты

* **Шероховатость поверхности** — верхний слой толщиной $d_r$ из эффективной среды Бруггемана 50 % плёнка / 50 % пустота: $\varepsilon_{\text{ema}}$ — положительный корень уравнения $\sum_i f_i \frac{\varepsilon_i - \varepsilon}{\varepsilon_i + 2\varepsilon} = 0$. Для типичной шероховатости $\sigma_{rms} \approx 0.5$–$0.7\,d_r$.
* **Неоднородность (градиент)** — линейный профиль $n(z) = n(\lambda)\,[1 + \delta\,(z/d - \tfrac12)]$, $z = 0$ у подложки, $z = d$ у поверхности; $\delta > 0$ означает рост $n$ к поверхности. Профиль реализован лестницей из $M$ однородных подслоёв ($M = 40$ в синтезе и в окончательном фите). Средний по толщине показатель не меняется, поэтому $\delta$ и дисперсия плохо коррелируют.

### 3.6. Прибор (синтез измерения)

Функция `synthesize` последовательно применяет:

1. фактический угол падения $\varphi_0 + \Delta\varphi$;
2. сдвиг шкалы длин волн: спектр считается в точках $\lambda_i + \Delta\lambda$, приписывается номинальным $\lambda_i$;
3. спектральную полосу FWHM: $\mathcal N, \mathcal C, \mathcal S$ вычисляются на мелкой сетке 0.5 нм с запасом по краям, свёртываются с гауссовым ядром ($\pm3.5\sigma$) и интерполируются на сетку прибора;
4. дрейф калибровки: смещение + линейный наклон по диапазону для Ψ и Δ;
5. шум: гауссов с $\sigma_\Psi(\lambda)$, $\sigma_\Delta(\lambda)$ (столбцы файла); в симуляторе $\sigma_\Psi(\lambda) = \sigma_{кр} + \sigma_{син}\,[(650-\lambda)/250]^2$ при $\lambda < 650$ нм, $\sigma_\Delta = k\,\sigma_\Psi / \max(\sin 2\Psi, 0.15)$ — рост шума Δ при малых Ψ, как у реальных RCE-приборов.

Генератор случайных чисел детерминированный (mulberry32 + полярный метод Бокса–Мюллера): одно и то же зерно даёт один и тот же спектр.

## 4. Алгоритм

### 4.0. Входные данные

Спектр $\{\lambda_i, \Psi_i, \Delta_i, \sigma_{\Psi,i}, \sigma_{\Delta,i}\}$ ($n$ точек), материал (справочные параметры дисперсии), подложка, номинальный угол $\varphi_0$, номинальная толщина $d_{ном}$ и разброс $\pm p\,\%$ (априорный интервал $[d_{min}, d_{max}]$), полоса прибора и неопределённость угла (только для генератора обучения).

Вектор невязки везде один и тот же:

$$\mathbf r = \left[\frac{\Psi_i - \Psi_i^{мод}}{\sigma_{\Psi,i}};\ \frac{\operatorname{wrap}(\Delta_i - \Delta_i^{мод})}{\sigma_{\Delta,i}}\right],\qquad \operatorname{wrap}: (-180°, 180°],$$

$\chi^2/\nu = \|\mathbf r\|^2 / (2n - p)$, $p$ — число свободных параметров.

### 4.1. Шаг 1 — опорный фит однородной плёнки

Модель: одна однородная плёнка на полубесконечной подложке; свободны $d, A, A_{uv}, E_g$.

1. **Грубый перебор толщины**: при справочной дисперсии считается $\chi^2(d)$ на сетке из 120 шагов (не мельче 0.5 нм) по априорному интервалу. Берутся локальные минимумы кривой, сортируются по $\chi^2$, три лучших — стартовые точки (защита от выбора соседнего порядка интерференции).
2. **Левенберг–Марквардт** (`lmFit`) из каждой стартовой точки: численный якобиан (прямые разности, шаг $10^{-4}\cdot$масштаб параметра), демпфирование $\lambda$ от $10^{-3}$ (×0.3 при успехе, ×5 при неудаче, до 12 попыток на итерацию), до 80 итераций, остановка при относительном уменьшении $\chi^2$ меньше $10^{-9}$; границы — отсечением. Ковариация $(J^TJ)^{-1}\chi^2/\nu$, формальные погрешности — корни диагонали.
3. Границы: $d \in [d_{min} - 0.3w,\ d_{max} + 0.3w]$ ($w$ — ширина априорного интервала), $A \in [0.2A_0, 4A_0]$, $A_{uv} \in [0, 3|A_{uv,0}| + 100]$, $E_g \in [\max(1.5, E_{g0} - 1),\ \min(E_0 - 0.15, E_{g0} + 1)]$.
4. Выбирается решение с наименьшим $\chi^2$. Результат: параметры, погрешности, остаток $\mathbf r_0$ длины $2n$, $\chi^2/\nu$.

**Каналы якорей.** По модели голой подложки при номинальном угле строится $\Delta_{sub}(\lambda)$; фаза полос $\phi(\lambda) = \operatorname{unwrap}(\Delta - \Delta_{sub})$ (знак выбирается так, чтобы фаза росла). Полуволновые якоря (HW) — точки $\phi = k\cdot360°$, четвертьволновые (QW) — $\phi = k\cdot360° + 180°$; $\lambda$ якорей находятся интерполяцией $\lambda(\phi)$. Шесть чисел каналов: среднее Ψ-остатка в HW-якорях и его разброс (канал градиента: знак минус при росте $n$ к поверхности), средний |Δ-остаток| в HW и в QW (канал шероховатости; для однородной плёнки Δ в этих точках «прибит» к значению подложки, и мешающие факторы там почти не действуют), RMS остатков Ψ и Δ. Если якорей меньше двух (тонкая плёнка или узкий диапазон), каналы обнуляются.

**Вектор признаков** для ИИ: $\mathbf x = [\mathbf r_0;\ \text{6 каналов}]$, размерность $2n + 6$.

### 4.2. Шаг 2 — обучение ИИ-модели на смоделированных остатках

Для условий текущего измерения генерируется $N$ примеров (по умолчанию 600, ползунок 200–2000), классы чередуются циклически (сбалансированно):

| класс | g | r | название |
|---|---|---|---|
| 0 | 0 | 0 | однородная плёнка |
| 1 | +1 | 0 | градиент, n растёт к поверхности |
| 2 | −1 | 0 | градиент, n падает к поверхности |
| 3 | 0 | 1 | шероховатость |
| 4 | +1 | 1 | градиент (n растёт) + шероховатость |
| 5 | −1 | 1 | градиент (n падает) + шероховатость |

Размеры дефектов: $|\delta|$ — с вероятностью ½ равномерно в тонкой шкале $[0.02\,\%,\ \min(2\,\%, \delta_{max})]$, иначе равномерно в $[2\,\%, \delta_{max}]$ (если $\delta_{max} > 2\,\%$); знак по классу; $d_r$ равномерно в $[0.02, 3]$ нм.

Мешающие факторы каждого примера (то, чего аналитик не знает точно): толщина равномерно в априорном интервале; $A$ и $A_{uv}$ ±5 % (плюс ±2 по $A_{uv}$), $E_0$ ±0.05, $C$ ±0.06, $E_g$ ±0.05 эВ; угол ±(неопределённость угла); полоса ±0.3 нм вокруг паспортной; сдвиг шкалы ±0.1 нм; дрейф Ψ (смещение ±0.01°, наклон ±0.015°) и Δ (±0.03°, ±0.04°); шум по столбцам σ измеренного файла.

Каждый пример синтезируется (`synthesize`, 40 подслоёв), фитируется той же опорной моделью (`referenceFit`) и превращается в вектор признаков. Это самая дорогая часть: 0.1–0.4 с на пример.

**Классификатор** — мультиномиальная логистическая регрессия (softmax): признаки стандартизируются (среднее и СКО по обучающей выборке), веса обучаются Adam (шаг 0.05, 250 эпох, полный батч) с L2-регуляризацией $2\cdot10^{-3}$. 25 % примеров (не меньше 30) откладываются для оценки точности — по всем размерам и «выше порога» ($|\delta| \ge 0.4\,\%$, $d_r \ge 0.4$ нм); затем модель дообучается на всех примерах.

**Регрессия размеров** — гребневая регрессия ($\alpha = 30$) на тех же признаках для $\delta$ (в %) и $d_r$ (нм); её оценки служат стартовыми значениями окончательного фита.

Половина обучающих градиентов в тонкой шкале нужна, чтобы расширение диапазона до 10–20 % не убило чувствительность к малым градиентам.

### 4.3. Шаг 3 — диагноз

Вектор признаков измеренного остатка подаётся в классификатор. Выводятся вероятности шести классов, а также агрегаты: $P(\text{градиент}) = p_1 + p_2 + p_4 + p_5$, $P(\delta < 0) = p_2 + p_5$, $P(\text{шероховатость}) = p_3 + p_4 + p_5$, и оценки размеров регрессией. Флажки модели окончательного фита заполняются по лучшему классу; их можно поправить вручную.

### 4.4. Шаг 4 — окончательный фит и решение

Модель: однородная плёнка + (EMA-слой, свободна $d_r \in [0, 12]$ нм) и/или (градиент, свободен $\delta \in [-20\,\%, 20\,\%]$), 40 подслоёв, старт из результата опорного фита и оценок регрессии. **Вето:** параметр дефекта, не отличимый от нуля на $3\sigma$ (формальная погрешность), убирается, и фит повторяется (не более двух проходов). Выводятся параметры с погрешностями, $\chi^2/\nu$ до и после, RMS остатков, графики остатка, отпечатка (Δ-остаток от Ψ-остатка) и $n(\lambda)$.

**Сверка с истиной** (только для встроенных и симулированных образцов): набор дефектов, толщина, $\delta$, $d_r$, $n(550)$, фактический угол, полоса и сдвиг шкалы.

**Разбор причин отклонения** — два уровня:

1. *Правила*: дефект ниже порога обнаружения (≈0.4 % и ≈0.4 нм при $\sigma_\Psi \approx 0.02°$); классификатор не уверен (< 60 %) или недообучен (< 80 % на отложенных); истинный размер вне диапазона обучения; ИИ выбрал верно, но вето отбросило дефект; канал якорей противоречил выбору ИИ; истинная толщина вне априорного интервала или ошибка толщины порядка периода полос (перепутан порядок интерференции); фактический угол отличается от номинала больше заявленной неопределённости (ошибка угла сдвигает линию подложки и имитирует градиент, ≈0.3 % на 0.1° при 60–65°); полоса в истине не совпадает с полосой генератора.
2. *Бюджет отклонения*: тот же фит при истинном наборе дефектов повторяется на спектрах, синтезированных из истины с последовательно убираемыми искажениями — шум, дрейф, сдвиг шкалы λ, полоса, ошибка угла, форма дисперсии ($E_0$, $C$, $E_{uv}$ как у образца). Разность соседних строк — вклад убранного фактора; остаток после всех — предел модели (дискретизация, EMA-смесь, локальный минимум). Порог «значимого» отклонения: 1.5 нм по толщине, 0.2 % по градиенту, 0.3 нм по слою, 0.005 по $n$.

## 5. Архитектура

### 5.1. Модули

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ index.html = src/app_template.html + src/ellip_core.js + examples/examples.json│
├──────────────────────────────────────────────────────────────────────────────┤
│ Интерфейс (app_template.html)                                                 │
│   состояние S: data, example (истина), cfg, prior, nuis, ref, refFeat,        │
│                train (model, rd, rr, метрики), probs, est, fin, finFlags       │
│   парсер xlsx/csv → setData → step1 → step2 (порциями) → step3 → step4        │
│   → causeAnalysis; clearFrom(k) чистит панели шагов k…4; графики Chart.js      │
├──────────────────────────────────────────────────────────────────────────────┤
│ Ядро (ellip_core.js; module.exports в Node, window.EllipCore в браузере)      │
│   комплексная арифметика → tlEps/filmN/filmNK → SUBSTRATES/substrateN         │
│   → buildLayers (EMA, лестница) → rhoStack (Эйри) → psiDeltaFromR/ncsFromR    │
│   → modelPsiDelta, synthesize (полоса, сдвиг, дрейф, шум), makeRng            │
│   → lmFit → referenceFit, finalFit → anchors, channels, featureVector         │
│   → trainSoftmax, ridge → CLASSES, trainingExample                            │
└──────────────────────────────────────────────────────────────────────────────┘
```

Внешние зависимости только у интерфейса: Chart.js 4.4.1 и SheetJS 0.18.5 (cdnjs), шрифт IBM Plex Sans (Google Fonts). Ядро не имеет зависимостей и одинаково работает в Node и в браузере — тесты и генерация примеров используют тот же код, что и приложение.

### 5.2. API ядра (основные функции)

| функция | назначение |
|---|---|
| `filmN(lam, m)`, `filmNK(lam, m)` | комплексный показатель плёнки `[n, −k]` / `{n, k}` по параметрам `m = {A, E0, C, Eg, Auv, Euv}` |
| `substrateN(key, lam)` | показатель подложки `[n, −k]` |
| `buildLayers(lam, d, m, delta, dRough, M)` | стопка слоёв сверху вниз: EMA-слой (если `dRough > 0`) + плёнка (одна или `M` подслоёв градиента) |
| `rhoStack(lam, layers, Nsub, phi)` | `r_p`, `r_s` для каждой λ |
| `modelPsiDelta(lam, Nsub, phi, d, m, delta, dRough, M)` | Ψ, Δ модели без полосы |
| `synthesize(lam, subKey, phiTrue, d, m, delta, dRough, opt, rng)` | «измерение»: `opt = {bw, lamOffset, driftPsi, driftDel, sigPsi, sigDel}` |
| `makeRng(seed)` | детерминированный ГСЧ: `uniform()`, `normal()`, `range(a, b)`, `int(n)` |
| `lmFit(residFn, x0, lo, hi, scale, maxIter)` | Левенберг–Марквардт с границами; возвращает `x, resid, chi2, cov, err` |
| `referenceFit(data, cfg, prior)` | опорный фит однородной плёнки; `data = {lam, psi, del, sigPsi, sigDel}`, `cfg = {mat, subKey, Nsub, phi}`, `prior = {dMin, dMax}` |
| `finalFit(data, cfg, prior, flags, p0)` | фит в модели `flags = {grad, rough}` со стартом `p0` |
| `anchors(lam, del, delSub)` | λ полуволновых (HW) и четвертьволновых (QW) якорей |
| `channels(lam, resid, HW, QW)` | шесть чисел каналов остатка |
| `featureVector(data, cfg, resid)` | остаток + каналы |
| `trainingExample(data, cfg, prior, nuis, rng, cls)` | один обучающий пример; `nuis = {deltaMax, roughMax, bw, phiErr}` |
| `trainSoftmax(X, y, K, opt)` | классификатор; `predictProba(x)` |
| `ridge(X, y, alpha)` | гребневая регрессия; `predict(x)` |
| `CLASSES`, `MATERIALS`, `SUBSTRATES` | справочники |

### 5.3. Поток данных

```
файл / встроенный образец / симулятор ──► S.data {lam, psi, del, sigPsi, sigDel}
                                                 │
   априорные условия ──► S.cfg, S.prior, S.nuis  │
                                                 ▼
                       шаг 1: referenceFit ──► S.ref (P, E, resid, chi2), S.refFeat
                                                 │
                       шаг 2: N × trainingExample ──► X, y ──► trainSoftmax, ridge ──► S.train
                                                 │
                       шаг 3: S.train.model.predictProba(S.refFeat) ──► S.probs, S.est, флажки
                                                 │
                       шаг 4: finalFit (+ вето) ──► S.fin ──► таблица, графики
                                                 │
            если есть истина (S.example.truth) ──► сверка ──► causeAnalysis (правила + бюджет)
```

Шаг 2 выполняется порциями по ~120 мс через `setTimeout`, чтобы интерфейс не замораживался и полоса прогресса обновлялась.

### 5.4. Сборка

`node tools/build.js` подставляет ядро и примеры в шаблон и записывает `index.html`. Результат сборки побайтно совпадает с опубликованным файлом при неизменных исходниках.

## 7. Форматы файлов

### 7.1. Входной спектр

* **.xlsx / .xls** — первый лист. Строка заголовка — первая строка, где ≥ 2 текстовых ячеек; столбцы распознаются по заголовку: λ (`λ`, `lam`, `wave`, `нм`, `nm`), Ψ (`ψ`/`psi` без `σ`, `sig`, `err`), Δ (`δ`/`delta` без них), σΨ (`σψ`, `sig…psi`, `err…psi`), σΔ (`σδ`, `sig…del`, `err…del`). Без заголовка — позиционно: λ, Ψ, Δ, σΨ, σΔ.
* **.csv / .txt** — разделитель `;`, табуляция или `,` (определяется автоматически); при разделителе, отличном от запятой, десятичная запятая допускается.
* Единицы: нм и градусы. Δ приводится к [0°, 360°); строки сортируются по λ; нужно не меньше 20 строк с числами. Если столбцов σ нет — берётся значение «σΨ по умолчанию» и $\sigma_\Delta = 2\sigma_\Psi$.

Тестовые файлы `examples/*.xlsx` содержат лист «Спектр» (λ, Ψ, Δ, σΨ, σΔ) и лист «Условия» (априорная информация, которую вводит аналитик); истина — в `examples/answer_key.xlsx`.

### 7.2. Экспорт

Кнопка «Скопировать спектр как CSV»: `lambda_nm;Psi_deg;Delta_deg;sigPsi_deg;sigDelta_deg`, четыре знака после запятой. Такой файл загружается обратно как файл пользователя.

### 7.3. `examples/examples.json`

Массив объектов `{id, file, title, mat, sub, phi, dNom, dRange, bw, lam[], psi[], del[], sigPsi[], sigDel[], truth: {d, delta, dRough, phiTrue, bw, lamOffset, mat: {A, E0, C, Eg, Auv, Euv}, n: {450, 550, 650, 750}}}`. Генерируется `tools/gen_examples.js` детерминированно (зёрна 101…505).

## 9. Точность, пороги, время

* Пороги обнаружения при $\sigma_\Psi \approx 0.02°$, одном угле и мешающих факторах по умолчанию: слой шероховатости ≈ 0.35–0.4 нм, градиент ≈ 0.2–0.4 %. Ниже — не ошибки ИИ, а предел данных.
* Точность классификатора на отложенных примерах: 75–90 % по всем размерам (включая заведомо необнаружимые), 95–99 % выше порога; растёт с числом примеров.
* Формальные погрешности фита занижены: систематика угла, полосы и шкалы λ в них не входит. Ошибка угла 0.05° при 60–65° эквивалентна градиенту ≈ 0.16 %.
* Время (одно ядро): опорный фит 0.02–0.5 с; обучающий пример 0.1–0.4 с (кремниевая подложка медленнее из-за поглощения); 600 примеров — 1–3 мин; окончательный фит 0.1–1 с; разбор причин 1–3 с.

## 10. Ограничения

* Один угол падения; задняя сторона подложки не моделируется (для тонких прозрачных подложек её нужно чернить или матировать).
* Список классов закрыт: шероховатость нижней границы, поглощение, анизотропия, нелинейный профиль будут «втиснуты» в ближайший класс; защита — контроль $\chi^2/\nu$ после окончательного фита.
* Форма дисперсии фиксирована ($E_0$, $C$, $E_{uv}$ справочные); материал должен быть прозрачен или слабо поглощать в диапазоне измерения.
* Классификатор привязан к конфигурации (материал, подложка, угол, интервал толщины, прибор): при их смене шаг 2 нужно повторить.
* Линейный профиль с $|\delta| > 20$ % и слои толще 12 нм не допускаются.
