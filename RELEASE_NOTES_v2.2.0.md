# SE-AI v2.2.0 — размеры дефектов по каждому дефекту отдельно; общая легенда якорных паттернов

**▶ Запустить приложение:** https://costapop.github.io/SE-AI/releases/v2.2.0/ · страница «Иллюстрации»: https://costapop.github.io/SE-AI/releases/v2.2.0/#demo

Версия развивает **v2.1.0**.

**Что сделано**

- **Размер дефекта, которого нет в окончательном фите, берётся из симулятора.** В v2.1.0 при выполненном окончательном фите все три размера брались из него, и дефект, не включённый в фит (например, k₄₀₀ у образца без поглощения), получал умолчание 1.0, хотя в полях «Дефекты» симулятора на «Анализе» стояло другое значение. Теперь источник выбирается по каждому дефекту: включён в окончательный фит → найденное значение (|δ| по модулю); иначе → поле симулятора; нуль и там → умолчание 1 % / 2 нм / 1.0·10⁻³. Строка под полями называет источник каждого размера.
- **Якорные паттерны: одна легенда на четыре панели.** Раньше легенда стояла только в левой верхней панели, управляла лишь ею и делала её ниже остальных. Теперь над сеткой 2 × 2 — общая легенда: щелчок по варианту плёнки скрывает или показывает его сразу на всех четырёх панелях, состояние сохраняется при смене единиц, темы и полноэкранного режима; при экспорте панели в PNG легенда рисуется в ней самой. Ось λ у всех панелей одинакова (диапазон измерения).
- **Оформление раздела** в обычном и полноэкранном режимах: панели одинаковой высоты, в полноэкранном режиме вся фигура (заголовок, переключатель единиц, легенда, четыре панели, подпись) умещается на экране без прокрутки.

**Проверки.** `npm run test:demo` (девять образцов; общая легенда, оси, скрытие рядов, строка-источник размеров), `npm run test:ui` (образец 09: k₄₀₀ из симулятора при фите без поглощения), `npm run verify:book`, `npm run verify:backside`, `npm run examples:check` — все пройдены; ядро не менялось.
