# Проверка физики и математики приложения по книге Фурмана и Тихонравова

Источник: Sh. A. Furman, A. V. Tikhonravov, *Basics of Optics of Multilayer Systems*, Editions Frontières, 1992 (глава 1 — теория спектральных характеристик слоистых сред). Проверка выполнена скриптом `test/verify_book.js` (`npm run verify:book`): формулы книги реализованы независимо от ядра приложения, результаты сравниваются численно.

## 1. Конвенции (разделы 1.1.1–1.1.3)

| положение книги | в приложении | результат |
|---|---|---|
| Временной множитель $e^{+i\omega t}$; тогда комплексный показатель имеет отрицательную мнимую часть, $\tilde n = n - ik$ (сноска 1 к разд. 1.1.1) | `N = [n, −k]` всюду: плёнка (`filmN`), подложки (`substrateN`), EMA-слой | совпадает |
| Дисперсия Тауца–Лоренца записана в литературе для $e^{-i\omega t}$ ($\varepsilon_2 \ge 0$); переход к конвенции книги — комплексное сопряжение (то же примечание книги) | `filmN`: $N = \sqrt{\varepsilon_1 + i\varepsilon_2}$, затем мнимая часть берётся с минусом | совпадает |
| Закон Снеллиуса $\alpha = n_a \sin\gamma_a$ одинаков во всех слоях; в поглощающей среде угол комплексный (1.1.10–1.1.11) | `cosT(N, s0²) = sqrt(1 − s0²/N²)`, главная ветвь | совпадает |
| Прошедшая волна в поглощающей подложке затухает: при $e^{+i\omega t}$ нужно $\mathrm{Im}(q_s) \le 0$ | для c-Si при 400 нм, 65°: $\mathrm{Im}(N\cos\gamma) = -0.392 < 0$ | выполнено |
| Френель для $s$: $r_s = (q_a - q_s)/(q_a + q_s)$, $q = n\cos\gamma$ | `fresnelPS`: $r_s = (N_i c_i - N_j c_j)/(N_i c_i + N_j c_j)$ | тождественно |
| Френель для $p$ через тангенциальные компоненты **E**: $r_p = (q_a - q_s)/(q_a + q_s)$, $q = n/\cos\gamma$; книга отмечает, что «очень часто» $r_p$ записывают с противоположным знаком (определение через **H**) | `fresnelPS`: $r_p = (N_j c_i - N_i c_j)/(N_j c_i + N_i c_j)$ — эллипсометрическое определение (Аззам–Башара, Фудзивара) | $r_p^{\text{прил}} = -\,r_p^{\text{книги}}$, проверено до $4\cdot10^{-15}$ |

Следствие последней строки: $\Delta^{\text{прил}} = \Delta^{\text{книги}} + 180°$. Выбор приложения соответствует эллипсометрическим приборам: для прозрачной подложки $\Delta = 180°$ ниже угла Брюстера и $0°$ выше, при нормальном падении $\rho = -1$ (проверено). Это не ошибка, а соглашение; в README оно оговорено.

## 2. Рекурсия Эйри против матричного метода Абелеса (разделы 1.2.1, 1.2.3)

Ядро вычисляет $r_p$, $r_s$ рекуррентной формулой (1.2.18) книги: $r_{j+1,0} = (r_{j+1,j} + r_{j,0}e^{-2i\varphi_j})/(1 + r_{j+1,j} r_{j,0} e^{-2i\varphi_j})$, $\varphi_j = k n_j d_j \cos\gamma_j$, от подложки к внешней среде. В тесте независимо реализован матричный метод: характеристические матрицы (1.2.9), произведение от внешней среды к подложке (1.2.11), формулы (1.2.13)–(1.2.14) для $t$ и $r$, $T = \mathrm{Re}(q_s)/\mathrm{Re}(q_a)\,|t|^2$ (1.1.23).

Стек из 42 слоёв (TiO₂ 1000 нм с градиентом +5 % как 40 подслоёв, EMA-слой 2 нм, подложка c-Si с поглощением), 65°, 400–800 нм: $\max|\Delta r_s| = 4\cdot10^{-15}$, $\max|r_p^{\text{прил}} + r_p^{\text{книги}}| = 4\cdot10^{-15}$, $\Psi$ и $\Delta$ совпадают до $10^{-12}$°.

## 3. Численный пример книги: таблица 1.2

Семнадцатислойный узкополосный фильтр $S\,(HL)^4\,xH\,(LH)^4$, $n_s = 1.52$, $n_H = 2.3 - 0.0002i$, $n_L = 1.35 - 0.0002i$, $\lambda_0 = 500$ нм, нормальное падение; книга приводит $T$, $R$, $A$ в 11 точках. Матричный метод из теста воспроизводит все 33 числа с точностью **0.001 %** при двух уточнениях, которые пришлось подобрать, потому что текст книги извлечён из PDF с искажениями: центральный слой имеет оптическую толщину $\lambda_0$ (четыре четвертьволновые), а столбец $R$ соответствует свету, падающему со стороны подложки ($T$ от направления не зависит и воспроизводится в обе стороны; $R$ при поглощении зависит — раздел 1.3.2). Рекурсия ядра для того же стека совпадает с матричным методом по $R$ прямого хода до $5\cdot10^{-12}$ %.

Этим одновременно проверены формулы Френеля, фазовая толщина $2\pi n d/\lambda$, знак мнимой части показателя (при неверном знаке $A < 0$) и энергетический баланс.

## 4. Неоднородный слой (разделы 1.1.2, 1.1.4)

Книга указывает, что ступенчатая аппроксимация непрерывного профиля даёт лишь первый порядок точности, и рекомендует интегрировать уравнения поля (1.1.9), (1.1.14) или уравнение Риккати для локальной функции отражения (1.1.19), (1.1.20):

$$\frac{dr}{dz} = \frac{ik}{2q_a}\left[q_a^2(1-r)^2 - (\varepsilon(z) - \alpha^2)(1+r)^2\right] \ (s),\qquad \frac{dr}{dz} = \frac{ik}{2q_a}\left[q_a^2\Big(1 - \frac{\alpha^2}{\varepsilon(z)}\Big)(1-r)^2 - \varepsilon(z)(1+r)^2\right] \ (p),$$

$r(0) = (q_a - q_s)/(q_a + q_s)$. Уравнения выведены заново из (1.1.9), (1.1.14) и (1.1.18) (в извлечённом тексте формулы читаются плохо) и реализованы дважды: независимо в тесте и в ядре (`rhoGraded`, RK4, шаг 0.5 нм; EMA-слой сверху добавляется шагом Эйри после пересчёта $r$ к среде ЭС через $w = v/u$).

Проверки: для однородной плёнки решение Риккати совпадает с Эйри до $10^{-9}$; сходимость по шагу четвёртого порядка (ошибка $1.7\cdot10^{-2}$° при 2 нм, $1.1\cdot10^{-3}$° при 1 нм, $6.8\cdot10^{-5}$° при 0.5 нм); ветвь с EMA-слоем при $\delta \to 0$ совпадает с Эйри.

Ошибка лестницы из $M$ подслоёв (центры подслоёв) относительно непрерывного профиля, TiO₂ 1000 нм на BK7, 65°, в единицах шума $\sigma_\Psi \approx 0.02°$, $\sigma_\Delta = 2.2\sigma_\Psi$ (RMS по 400–800 нм):

| $\delta$ | $M = 10$ | $M = 20$ | $M = 40$ | $M = 80$ | $M = 160$ |
|---|---|---|---|---|---|
| 1 % | Ψ 3.0σ, Δ 4.8σ | 0.12σ, 0.45σ | 0.03σ, 0.10σ | 0.01σ, 0.03σ | 0.00σ, 0.01σ |
| 5 % | 14σ, 26σ | 0.56σ, 2.4σ | 0.13σ, 0.55σ | 0.03σ, 0.13σ | 0.01σ, 0.03σ |
| 12 % | 30σ, 81σ | 1.2σ, 6.1σ | 0.27σ, 1.4σ | 0.07σ, 0.35σ | 0.02σ, 0.09σ |

Ошибка убывает как $1/M^2$: лестница по центрам подслоёв даёт второй порядок, а не первый (замечание книги относится к наивной ступенчатой аппроксимации). Принятые решения: истина в симуляторе считается непрерывным профилем (Риккати, по умолчанию); окончательный фит использует 40 подслоёв и переходит на 80 при $|\delta| > 4$ % (ошибка модели $\le 0.35\sigma$ во всём допустимом диапазоне $\pm20$ %); генерация обучающих остатков остаётся на 40 подслоях (ошибка $\le 0.55\sigma$ при 5 % не влияет на классификацию).

## 5. Энергия и предельные случаи (раздел 1.1.5)

* Непоглощающая плёнка на стекле, 60°: $R + T - 1 = 2\cdot10^{-16}$ для обеих поляризаций.
* Поглощающая плёнка (TiO₂ при 340 нм, $N = 2.853 - 0.108i$) на BK7, 60°: $A_s = 0.403$, $A_p = 0.701$ — положительны.
* Угол Брюстера BK7 при 550 нм (56.63°): $|r_p| < 10^{-6}$; голый диэлектрик: $\Delta = 180°$ при 45°, $0°$ при 70°; нормальное падение: $r_p = -r_s$.

## 6. Что в книге не рассматривается и как проверено отдельно

* **Дисперсия Тауца–Лоренца + УФ-полюс**: аналитическое выражение $\varepsilon_1$ (Jellison–Modine) сверено с численным интегралом Крамерса–Кронига (совпадение до $10^{-6}$ в прототипе на Python; ядро на JavaScript совпадает с прототипом до $10^{-13}$ по Ψ, Δ). Условие существования $4E_0^2 > C^2$ и $E_g < E_0$ контролируется в интерфейсе.
* **Эффективная среда Бруггемана**: корень квадратного уравнения удовлетворяет исходному уравнению ЭС с невязкой $10^{-17}$, $1 < \varepsilon_{\text{ema}} < \varepsilon_{\text{плёнки}}$, мнимая часть показателя отрицательна.
* **Нормированные элементы матрицы Мюллера** $\mathcal N, \mathcal C, \mathcal S$ и свёртка со спектральной полосой: усредняются интенсивностные величины, а не углы; $\Psi = \tfrac12\arccos\mathcal N$, $\Delta = \operatorname{atan2}(\mathcal S, \mathcal C)$ восстанавливают Ψ, Δ точно при нулевой полосе.
* **Производные по параметрам** (раздел 1.4.1 книги даёт аналитические выражения): в приложении якобиан численный; при необходимости ускорения фита аналитические производные книги — очевидное направление.

## 7. Итог

Ошибок в физике и математике ядра не найдено. Единственное расхождение с книгой — знак $r_p$ — является осознанным соглашением эллипсометрии и теперь оговорено в README. По результатам проверки внесены два улучшения, следующие из книги: непрерывный профиль неоднородности через уравнение Риккати (истина в симуляторе) и адаптивное число подслоёв в окончательном фите.
