# SE-AI — дефекты тонкой плёнки по остатку эллипсометрического фита

Одностраничное веб-приложение (все вычисления в браузере), которое по спектру Ψ(λ), Δ(λ) и априорной информации об образце находит наиболее вероятный набор дефектов тонкой плёнки и выполняет окончательный фит в выбранной модели.

**Схема:** опорный фит однородной плёнки → остаток фита как «отпечаток пальца» → ИИ-модель, обученная на остатках, смоделированных для тех же условий → вероятности наборов дефектов → окончательный фит в выбранной модели → сверка со скрытой истиной и разбор причин отклонения (для симулированных образцов).

Дефекты: **неоднородность показателя преломления по глубине** (линейный градиент любого знака), **шероховатость поверхности** (слой Бруггемана) и **поглощение** (причинный хвост ниже края поглощения; размер — k хвоста при 400 нм). Подложка по умолчанию полубесконечная; для плоскопараллельной прозрачной подложки можно включить **отражение от задней стороны** — оно складывается с передним некогерентно с заданной (из независимого измерения, не фитируемой) долей.

Методическая основа — статистический шаг ограничен выбором модели из короткого списка, параметры внутри модели определяет физика: К. Попов, *AI-assisted model discovery in spectroscopic ellipsometry* (рукопись, 2026); о единственности восстановления в этом классе моделей — K. Popov, Phys. Scr. **101** (2026) 295206.

*English summary.* A single-page browser app that (1) fits a homogeneous-film model to a measured spectroscopic-ellipsometry spectrum, (2) trains a multinomial logistic regression on fit residuals simulated for the same measurement conditions (twelve classes: no defect, index gradient of either sign, surface roughness, sub-gap absorption, and their combinations), (3) reports class probabilities for the measured residual, and (4) performs the final fit in the selected model. Absorption is modelled as a Kramers–Kronig-consistent Tauc–Lorentz tail below the band edge; its residual signature is the decay of fringe contrast towards the blue edge, unlike the uniform Ψ shift at half-wave points produced by an index gradient. Incoherent backside reflection from a plane-parallel transparent substrate can be switched on with a given (independently measured, not fitted) collected fraction; it enters the simulator, the training set and the fits. A measurement simulator with realistic instrument effects and nine ready-made test spectra (with an answer key; three of them on real materials with an absorption edge inside the measured range — Si-rich SiNₓ:H, CeO₂, WO₃ — and one on a 1 mm substrate with backside reflection) are included.

## 1. Быстрый старт

1. Откройте `index.html` в браузере (двойным щелчком или через любой статический сервер, например `python3 -m http.server`). Если для репозитория включён GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root), приложение доступно по адресу https://costapop.github.io/SE-AI/ без установки. Нужен доступ в интернет для загрузки Chart.js, SheetJS и шрифта с CDN; сами вычисления идут локально.
2. В панели «Спектр» уже выбран первый тестовый образец (TiO₂ на BK7, 65°). Нажмите **«Выполнить все шаги»**.
3. Через 2–4 минуты (обучение ИИ на 800 примерах двенадцати классов) внизу появятся: окончательный фит, сверка со скрытой истиной образца и разбор причин отклонения.
4. Чтобы проверить свой спектр — загрузите файл `.xlsx`/`.csv` (формат в [разделе 7](#7-форматы-файлов)), задайте материал, подложку, угол и номинальную толщину и снова нажмите «Выполнить все шаги».
5. Чтобы проверить алгоритм на произвольной комбинации дефектов — задайте её в панели «Симулятор измерения» и нажмите **«Сгенерировать измерение»**: спектр станет текущим, истина будет скрыта до шага 4.

Шаги можно запускать и по отдельности (кнопки 1–4). Перед каждым запуском шага панели этого и всех нижестоящих шагов очищаются.

## 3. Физическая модель

### 3.1. Конвенции

* Комплексный показатель $N = n - ik$, фазовый множитель $e^{-2i\beta}$, временной множитель $e^{+i\omega t}$ (Аззам–Башара; так же считают приборы).
* $\rho = r_p / r_s = \tan\Psi\, e^{i\Delta}$, $\Delta \in [0°, 360°)$.
* Угол падения $\varphi_0$ задаётся в градусах; $\cos\theta_j = \sqrt{1 - (\sin\varphi_0 / N_j)^2}$ с главной ветвью корня.
* Знак $r_p$ — эллипсометрический (через **H**, Аззам–Башара): при нормальном падении $r_p = -r_s$, для прозрачной подложки $\Delta = 180°$ ниже угла Брюстера и $0°$ выше. В книге Фурмана–Тихонравова $r_p$ определён через тангенциальную компоненту **E** и имеет противоположный знак, поэтому $\Delta$ там отличается на 180°. Полная сверка ядра с книгой — в [docs/VERIFICATION.md](docs/VERIFICATION.md).

### 3.2. Отражение от стопки слоёв

Коэффициенты Френеля на границе $i \to j$:

$$r_p = \frac{N_j \cos\theta_i - N_i \cos\theta_j}{N_j \cos\theta_i + N_i \cos\theta_j},\qquad r_s = \frac{N_i \cos\theta_i - N_j \cos\theta_j}{N_i \cos\theta_i + N_j \cos\theta_j}.$$

Рекурсия Эйри снизу вверх для каждого слоя $j$ толщины $d_j$:

$$r \leftarrow \frac{r_{\text{верх}} + r\, X_j}{1 + r_{\text{верх}}\, r\, X_j},\qquad X_j = e^{-2i\beta_j},\quad \beta_j = \frac{2\pi d_j}{\lambda} N_j \cos\theta_j .$$

Из $r_p$, $r_s$ вычисляются Ψ, Δ, а также нормированные элементы матрицы Мюллера

$$\mathcal N = \frac{|r_s|^2 - |r_p|^2}{|r_p|^2 + |r_s|^2},\quad \mathcal C = \frac{2\,\mathrm{Re}(r_p r_s^*)}{|r_p|^2 + |r_s|^2},\quad \mathcal S = \frac{2\,\mathrm{Im}(r_p r_s^*)}{|r_p|^2 + |r_s|^2},$$

через которые выполняется свёртка со спектральной полосой (усредняются именно $\mathcal N, \mathcal C, \mathcal S$, а не углы): $\Psi = \tfrac12 \arccos\mathcal N$, $\Delta = \operatorname{atan2}(\mathcal S, \mathcal C)$.

### 3.3. Дисперсия плёнки: Тауц–Лоренц + УФ-полюс

Физически допустимая (причинная, согласованная с преобразованием Крамерса–Кронига) модель диэлектрической функции $\varepsilon = \varepsilon_1 + i\varepsilon_2$:

$$\varepsilon_2(E) = \begin{cases} \dfrac{A E_0 C (E - E_g)^2}{\left[(E^2 - E_0^2)^2 + C^2 E^2\right] E}, & E > E_g \\ 0, & E \le E_g \end{cases}$$

$\varepsilon_1(E)$ — аналитическое КК-выражение Джеллисона–Модина (1996, с исправлением опечаток), плюс полюс Зельмейера для переходов выше измеряемого диапазона и $\varepsilon_\infty = 1$:

$$\varepsilon_1(E) = 1 + \varepsilon_1^{TL}(E) + \frac{A_{uv}}{E_{uv}^2 - E^2}.$$

Параметры: $A$, $E_0$, $C$, $E_g$ (эВ), $A_{uv}$ (эВ²), $E_{uv}$ (эВ). В фите свободны $A$, $A_{uv}$, $E_g$; $E_0$, $C$, $E_{uv}$ фиксируются справочными значениями (иначе при видимом диапазоне и прозрачной плёнке они не определяются). $N = \sqrt{\varepsilon}$, $k \ge 0$.

**Хвост поглощения** (дефект «поглощение», см. 3.5) — второй осциллятор Тауца–Лоренца с теми же $E_0$, $C$, порогом $E_t$ = `TAIL_ET` = 1.2 эВ и силой $A_k$:

$$\varepsilon_2^{tail}(E) = \frac{A_k E_0 C\,(E - E_t)^2}{\left[(E^2 - E_0^2)^2 + C^2E^2\right]E}\ (E > E_t),\qquad \varepsilon = \varepsilon^{TL} + \varepsilon^{uv} + \varepsilon^{tail},$$

$\varepsilon_1^{tail}$ — то же аналитическое КК-выражение, так что хвост причинен (проверено численным интегралом Крамерса–Кронига, `npm run verify:book`). Его $k$ растёт к синему краю примерно как $(E - E_t)^2/E \cdot L(E)$ — в 20–40 раз от 800 к 400 нм. $A_k$ — внутренний параметр фита; наружу выводится $k_{400}$ — $k$ хвоста при 400 нм ($k$ плёнки с хвостом минус $k$ без него; `tailK400`, обратное `tailAk`). $A_k = 0$ возвращает чистый материал.

### 3.4. Подложки (полубесконечные)

| ключ | подложка | модель |
|---|---|---|
| bk7 | стекло BK7 | формула Зельмейера Schott N-BK7, k = 0 |
| silica | плавленый кварц | Зельмейер Malitson (1965), k = 0 |
| si | кремний c-Si | таблица n, k (400–1000 нм, по Aspnes–Studna 1983) с линейной интерполяцией |
| glass152 | стекло n = 1.52 | без дисперсии, k = 0 |

**Задняя сторона подложки** (флажок в панели «Спектр», параметры в «Априорных условиях»). Для плоскопараллельной прозрачной подложки пучки, отражённые её задней гранью, приходят в детектор некогерентно с передним (толщина подложки много больше длины когерентности), и складываются не амплитуды, а матрицы Мюллера пучков. Пучок $m \ge 1$ имеет амплитуды $A_j^{(m)} = t_j\,(r^b_j)^m (r'_j)^{m-1} t'_j$ ($j = p, s$): $t_j$ — пропускание стопки из воздуха в подложку, $r'_j$ — её отражение со стороны подложки, $t'_j$ — пропускание из подложки наружу, $r^b_j$ — френелевское отражение задней грани (подложка → воздух под внутренним углом). Фазы хода по подложке одинаковы для p и s и в $A_p A_s^*$ сокращаются, поэтому суммы геометрические:

$$\sum_m |A_j^{(m)}|^2 = \frac{|t_j t'_j|^2 |r^b_j|^2 w}{1 - |r'_j r^b_j|^2 w},\qquad \sum_m A_p^{(m)} A_s^{(m)*} = \frac{t_p t'_p (t_s t'_s)^* r^b_p r^{b*}_s\, w}{1 - r'_p r'^*_s r^b_p r^{b*}_s\, w},\qquad w = |e^{-2ik d_s N_s\cos\gamma_s}|^2,$$

и измеряемые $\mathcal N, \mathcal C, \mathcal S$ строятся из $I_j = |r_j|^2 + f\sum_m|A_j^{(m)}|^2$ и $Z = r_p r_s^* + f\sum_m A_p^{(m)}A_s^{(m)*}$, где $f \in [0, 1]$ — **доля** света задней стороны, попавшая в детектор (для плоскопараллельной подложки и полностью собранного пучка $f = 1$; часть пучка может уходить мимо детектора из-за бокового смещения $2 d_s \tan\gamma_s$). Доля **задана** из независимого измерения (например, по голой подложке) и в фите **не варьируется**; в обучающей выборке она разыгрывается в пределах указанной неопределённости. Толщина подложки $d_s$ нужна только для множителя $w$ — для стекла и кварца $k_s = 0$ и $w = 1$, для c-Si 0.5 мм $w \approx 10^{-8}$ и задняя сторона исчезает сама. Коэффициенты $r, t, r', t'$ считаются матричным методом Абелеса: для стопки в обратном порядке $M' = J M^{\mathsf T} J$, откуда при общем знаменателе $den = q_a m_{11} + q_a q_s m_{12} + q_s m_{22} + m_{21}$: $r = (q_a m_{11} + q_a q_s m_{12} - q_s m_{22} - m_{21})/den$, $t = 2q_a/den$, $r' = (-q_a m_{11} + q_a q_s m_{12} + q_s m_{22} - m_{21})/den$, $t' = 2q_s/den$ (проверено против прямого расчёта обращённой стопки и классической формулы $R + T T_b R_b/(1 - R_b^2)$ для пластины, см. [docs/VERIFICATION.md](docs/VERIFICATION.md)). Эффект велик: для TiO₂ 1 мкм на BK7 при 65° и $f = 1$ Ψ меняется до 2.6°, Δ — до 26°; без учёта задней стороны фит такого спектра даёт толщину с ошибкой 60 нм и градиент −7 % вместо −0.8 %. С задней стороной образец частично деполяризует, а Ψ, Δ становятся «эффективными» ($\Psi = \tfrac12\arccos\mathcal N$, $\Delta = \operatorname{atan2}(\mathcal S, \mathcal C)$); якобиан фита в этом режиме считается центральными разностями (аналитический выведен для $r_p$, $r_s$), фит в 2–3 раза медленнее; непрерывный профиль градиента в симуляторе заменяется лестницей из 160 подслоёв (уравнение Риккати даёт только отражение).

### 3.5. Дефекты

* **Шероховатость поверхности** — верхний слой толщиной $d_r$ из эффективной среды Бруггемана 50 % плёнка / 50 % пустота: $\varepsilon_{\text{ema}}$ — положительный корень уравнения $\sum_i f_i \frac{\varepsilon_i - \varepsilon}{\varepsilon_i + 2\varepsilon} = 0$. Для типичной шероховатости $\sigma_{rms} \approx 0.5$–$0.7\,d_r$.
* **Неоднородность (градиент)** — линейный профиль $n(z) = n(\lambda)\,[1 + \delta\,(z/d - \tfrac12)]$, $z = 0$ у подложки, $z = d$ у поверхности; $\delta > 0$ означает рост $n$ к поверхности. В модели фита профиль реализован лестницей из $M$ однородных подслоёв по центрам ($M = 40$; при $|\delta| > 4$ % фит повторяется с $M = 80$ — ошибка лестницы не выше $0.35\sigma$). В симуляторе истинный спектр по умолчанию считается для непрерывного профиля интегрированием уравнения Риккати для локальной функции отражения (Фурман–Тихонравов, 1.1.19–1.1.20; RK4, шаг 0.5 нм) — см. `rhoGraded` и [docs/VERIFICATION.md](docs/VERIFICATION.md). Средний по толщине показатель не меняется, поэтому $\delta$ и дисперсия плохо коррелируют.
* **Поглощение** — хвост ниже края (3.3): плёнка поглощает больше, чем идеальная плёнка того же материала, и тем сильнее, чем ближе к синему краю. Единственный параметр — сила хвоста $A_k$ (наружу — $k_{400}$, $k$ хвоста при 400 нм; в фите $k_{400} \in [0, 0.05]$). Хвост масштабируется вместе с $n$ в градиентных подслоях и входит в слой Бруггемана через $\varepsilon$ плёнки. Сигнатура в остатке опорного фита отличается от градиента: градиент сдвигает Ψ в полуволновых точках примерно одинаково по всему диапазону, поглощение гасит контраст полос ($\propto k(\lambda)\,d/\lambda$), и гашение растёт к синему краю — см. каналы якорей в 4.1. Порог обнаружения ≈ $1$–$3\cdot10^{-4}$ по $k_{400}$ при толщине ~1 мкм и $\sigma_\Psi \approx 0.02°$ (растёт как $1/d$).

### 3.6. Прибор (синтез измерения)

Функция `synthesize` последовательно применяет:

1. фактический угол падения $\varphi_0 + \Delta\varphi$;
2. сдвиг шкалы длин волн: спектр считается в точках $\lambda_i + \Delta\lambda$, приписывается номинальным $\lambda_i$;
3. спектральную полосу FWHM: $\mathcal N, \mathcal C, \mathcal S$ вычисляются на мелкой сетке 0.5 нм с запасом по краям, свёртываются с гауссовым ядром ($\pm3.5\sigma$) и интерполируются на сетку прибора;
4. дрейф калибровки: смещение + линейный наклон по диапазону для Ψ и Δ;
5. шум: гауссов с $\sigma_\Psi(\lambda)$, $\sigma_\Delta(\lambda)$ (столбцы файла); в симуляторе $\sigma_\Psi(\lambda) = \sigma_{кр} + \sigma_{син}\,[(650-\lambda)/250]^2$ при $\lambda < 650$ нм, $\sigma_\Delta = k\,\sigma_\Psi / \max(\sin 2\Psi, 0.15)$ — рост шума Δ при малых Ψ, как у реальных RCE-приборов.

Генератор случайных чисел детерминированный (mulberry32 + полярный метод Бокса–Мюллера): одно и то же зерно даёт один и тот же спектр.

## 4. Алгоритм

### 4.0. Входные данные

Спектр $\{\lambda_i, \Psi_i, \Delta_i, \sigma_{\Psi,i}, \sigma_{\Delta,i}\}$ ($n$ точек), материал (справочные параметры дисперсии), подложка, номинальный угол $\varphi_0$, номинальная толщина $d_{ном}$ и разброс $\pm p\,\%$ (априорный интервал $[d_{min}, d_{max}]$), полоса прибора и неопределённость угла (только для генератора обучения); при флажке «задняя сторона» — заданная доля $f$, её неопределённость (только для генератора обучения) и толщина подложки.

Вектор невязки везде один и тот же:

$$\mathbf r = \left[\frac{\Psi_i - \Psi_i^{мод}}{\sigma_{\Psi,i}};\ \frac{\operatorname{wrap}(\Delta_i - \Delta_i^{мод})}{\sigma_{\Delta,i}}\right],\qquad \operatorname{wrap}: (-180°, 180°],$$

$\chi^2/\nu = \|\mathbf r\|^2 / (2n - p)$, $p$ — число свободных параметров.

### 4.1. Шаг 1 — опорный фит однородной плёнки

Модель: одна однородная плёнка на полубесконечной подложке; свободны $d, A, A_{uv}, E_g$.

1. **Грубый перебор толщины**: при справочной дисперсии считается $\chi^2(d)$ на сетке из 120 шагов (не мельче 0.5 нм) по априорному интервалу. Берутся локальные минимумы кривой, сортируются по $\chi^2$, три лучших — стартовые точки (защита от выбора соседнего порядка интерференции).
2. **Левенберг–Марквардт с аналитическим якобианом** (`lmFitJac`) из каждой стартовой точки. Производные Ψ, Δ по параметрам считаются точно по формулам раздела 1.4.1 книги Фурмана–Тихонравова: матрицы $D_j = \partial M_j/\partial d_j$ (1.4.9) и $\partial M_j/\partial \tilde n_j$, матрица $\Psi_r$ (1.4.10), $\partial r/\partial x_j = \mathrm{Tr}(\Psi_r^{j-1} M^{j+1} X_j)$ (1.4.12, 1.4.16), затем цепное правило к глобальным параметрам ($d$ — через толщины подслоёв, $\delta$ и дисперсия — через показатели подслоёв и слоя ЭС) и $d\Psi = \tfrac12\sin 2\Psi\,\mathrm{Re}(\rho'/\rho)$, $d\Delta = \mathrm{Im}(\rho'/\rho)$. Якобиан по 6 параметрам стоит как ~4 вычисления модели вместо 7–12 при конечных разностях и не имеет ошибки усечения (сверка с центральными разностями — $10^{-8}$ относительных, `npm run verify:book`). Параметры масштабированы преобразованием $x = x_{min} + (x_{max} - x_{min})(1 + \sin\theta)/2$: внутренние переменные $\theta$ безразмерны и O(1), границы соблюдаются гладко, без отсечения шага. Демпфирование — по Нильсену (по коэффициенту выигрыша $\rho$ = фактическое/предсказанное уменьшение $\chi^2$), с диагональным масштабированием Марквардта; пробные шаги считаются без якобиана; геодезическое ускорение (Transtrum–Sethna: вторая производная невязки вдоль шага по двум дополнительным вычислениям модели) сокращает число итераций в узких «пологих» долинах, типичных для сильно коррелированных $A$, $A_{uv}$, $E_g$, в 2–3 раза. Остановка при относительном уменьшении $\chi^2$ меньше $10^{-8}$ или шаге меньше $10^{-7}$; ковариация $(J^TJ)^{-1}\chi^2/\nu$ по аналитическому якобиану в решении.
3. Границы: $d \in [d_{min} - 0.3w,\ d_{max} + 0.3w]$ ($w$ — ширина априорного интервала), $A \in [0.2A_0, 4A_0]$, $A_{uv} \in [0, 3|A_{uv,0}| + 100]$, $E_g \in [\max(1.5, E_{g0} - 1),\ \min(E_0 - 0.15, E_{g0} + 1)]$.
4. Выбирается решение с наименьшим $\chi^2$. Результат: параметры, погрешности, остаток $\mathbf r_0$ длины $2n$, $\chi^2/\nu$.

**Каналы якорей.** По модели голой подложки при номинальном угле (с задней стороной, если она включена) строится $\Delta_{sub}(\lambda)$; фаза полос $\phi(\lambda) = \operatorname{unwrap}(\Delta - \Delta_{sub})$ (знак выбирается так, чтобы фаза росла). Полуволновые якоря (HW) — точки $\phi = k\cdot360°$, четвертьволновые (QW) — $\phi = k\cdot360° + 180°$; $\lambda$ якорей находятся интерполяцией $\lambda(\phi)$. В полуволновых точках однородная прозрачная плёнка «отсутствует», и Ψ равен Ψ подложки при любых $n$ и $d$, поэтому Ψ-остаток в HW-якорях не зависит от того, как опорный фит подобрал дисперсию, и читает дефекты напрямую. Восемь чисел каналов: среднее Ψ-остатка в HW-якорях и его разброс (канал градиента: знак минус при росте $n$ к поверхности), средний |Δ-остаток| в HW и в QW (канал шероховатости; для однородной плёнки Δ в этих точках «прибит» к значению подложки, и мешающие факторы там почти не действуют), RMS остатков Ψ и Δ, и два канала поглощения — перепад Ψ-остатка между синей и красной половинами якорей, $\langle r_\Psi(HW)\rangle_{синие} - \langle r_\Psi(HW)\rangle_{красные}$ и то же по QW-якорям (затухание контраста полос к синему краю: градиент сдвигает Ψ в HW-точках примерно одинаково по диапазону, поглощение — тем сильнее, чем ближе к синему краю; в четвертьволновых точках контраст гасится с противоположной стороны полосы). Половины — по середине диапазона λ; если одна пуста — по номеру якоря. Если HW-якорей меньше двух (тонкая плёнка или узкий диапазон), каналы обнуляются.

**Вектор признаков** для ИИ: $\mathbf x = [\mathbf r_0;\ \text{8 каналов}]$, размерность $2n + 8$.

### 4.2. Шаг 2 — обучение ИИ-модели на смоделированных остатках

Для условий текущего измерения генерируется $N$ примеров (по умолчанию 800, ползунок 200–3000), классы чередуются циклически (сбалансированно). Классы — произведение градиент $g \in \{0, +1, -1\}$ × шероховатость $r \in \{0, 1\}$ × поглощение $a \in \{0, 1\}$, двенадцать штук:

| класс | g | r | a | название |
|---|---|---|---|---|
| 0 | 0 | 0 | 0 | однородная плёнка |
| 1 | +1 | 0 | 0 | градиент, n растёт к поверхности |
| 2 | −1 | 0 | 0 | градиент, n падает к поверхности |
| 3 | 0 | 1 | 0 | шероховатость |
| 4 | +1 | 1 | 0 | градиент (n растёт) + шероховатость |
| 5 | −1 | 1 | 0 | градиент (n падает) + шероховатость |
| 6 | 0 | 0 | 1 | поглощение |
| 7 | +1 | 0 | 1 | градиент (n растёт) + поглощение |
| 8 | −1 | 0 | 1 | градиент (n падает) + поглощение |
| 9 | 0 | 1 | 1 | шероховатость + поглощение |
| 10 | +1 | 1 | 1 | градиент (n растёт) + шероховатость + поглощение |
| 11 | −1 | 1 | 1 | градиент (n падает) + шероховатость + поглощение |

Размеры дефектов: $|\delta|$ — с вероятностью ½ равномерно в тонкой шкале $[0.02\,\%,\ \min(2\,\%, \delta_{max})]$, иначе равномерно в $[2\,\%, \delta_{max}]$ (если $\delta_{max} > 2\,\%$); знак по классу; $d_r$ равномерно в $[0.02, 3]$ нм; $k_{400}$ — так же в двух шкалах: $[2\cdot10^{-5}, 10^{-3}]$ и $[10^{-3}, k_{max}]$ ($k_{max}$ — поле «Макс. k₄₀₀», по умолчанию $5\cdot10^{-3}$), сила хвоста $A_k$ вычисляется из $k_{400}$ для дисперсии данного примера.

Мешающие факторы каждого примера (то, чего аналитик не знает точно): толщина равномерно в априорном интервале; $A$ и $A_{uv}$ ±5 % (плюс ±2 по $A_{uv}$), $E_0$ ±0.05, $C$ ±0.06, $E_g$ ±0.05 эВ; угол ±(неопределённость угла); полоса ±0.3 нм вокруг паспортной; сдвиг шкалы ±0.1 нм; дрейф Ψ (смещение ±0.01°, наклон ±0.015°) и Δ (±0.03°, ±0.04°); шум по столбцам σ измеренного файла; при включённой задней стороне — её доля ±(неопределённость доли), тогда как опорный фит примера использует заданную долю.

Каждый пример синтезируется (`synthesize`, 40 подслоёв), фитируется той же опорной моделью (`referenceFit`) и превращается в вектор признаков. Это самая дорогая часть: 0.1–0.4 с на пример.

**Классификатор** — мультиномиальная логистическая регрессия (softmax): признаки стандартизируются (среднее и СКО по обучающей выборке), веса обучаются Adam (шаг 0.05, 250 эпох, полный батч) с L2-регуляризацией $2\cdot10^{-3}$. 25 % примеров (не меньше 30) откладываются для оценки точности — по всем размерам и «выше порога» ($|\delta| \ge 0.4\,\%$, $d_r \ge 0.4$ нм, $k_{400} \ge 2\cdot10^{-4}$); затем модель дообучается на всех примерах.

**Регрессия размеров** — гребневая регрессия ($\alpha = 30$) на тех же признаках для $\delta$ (в %), $d_r$ (нм) и $k_{400}$ (в $10^{-3}$); её оценки служат стартовыми значениями окончательного фита.

Половина обучающих градиентов (и хвостов поглощения) в тонкой шкале нужна, чтобы расширение диапазона не убило чувствительность к малым дефектам. С двенадцатью классами на класс приходится $N/12$ примеров: при $N = 300$ классификатор ещё путает соседние сочетания (добавляет ложный градиент), при $N \ge 600$ на тестовых образцах он устойчив; точность растёт примерно до 2000–3000.

### 4.3. Шаг 3 — диагноз

Вектор признаков измеренного остатка подаётся в классификатор. Выводятся вероятности двенадцати классов, а также агрегаты: $P(\text{градиент}) = \sum_{g \ne 0} p$, $P(\delta < 0) = \sum_{g = -1} p$, $P(\text{шероховатость}) = \sum_{r = 1} p$, $P(\text{поглощение}) = \sum_{a = 1} p$, и оценки размеров регрессией. Флажки модели окончательного фита (градиент, шероховатость, поглощение) заполняются по лучшему классу; их можно поправить вручную.

### 4.4. Шаг 4 — окончательный фит и решение

Модель: однородная плёнка + (EMA-слой, свободна $d_r \in [0, 12]$ нм) и/или (градиент, свободен $\delta \in [-20\,\%, 20\,\%]$) и/или (хвост поглощения, свободна $A_k$, что соответствует $k_{400} \in [0, 0.05]$), 40 подслоёв. **Глобальный старт:** кандидаты — толщина опорного фита и до двух альтернативных локальных минимумов его кривой $\chi^2(d)$ (если их грубый $\chi^2$ не хуже лучшего более чем в 5 раз) × оба знака градиента (если оценка $|\delta|$ регрессией не превышает 1 %); каждый кандидат разведывается ЛМ на грубой модели (10 подслоёв, 25 итераций), лучший бассейн дотягивается на 40 подслоях до сходимости. Это защищает от соседнего порядка интерференции и от неверного знака градиента (проверено: при старте с $\delta = +0.5\,\%$ и опорном фите в соседнем порядке найдено истинное $\delta = -8\,\%$ и верная толщина). При поглощении перед этим идёт ещё один раунд разведки: опорный фит без хвоста компенсирует затухание полос дисперсией ($A$ и $E_g$ уходят вверх), и старт из него ведёт в ложный минимум — поэтому перебираются старты по силе хвоста (оценка ИИ и $k_{400} = 10^{-4}, 10^{-3}, 10^{-2}$) × дисперсия (опорный фит / справочник) при основной толщине, лучший по $\chi^2$ задаёт дисперсию и хвост для основного раунда (проверено: HfO₂/Si при $k_{400} = 10^{-3}$ и Si₃N₄/Si при $3\cdot10^{-3}$ из одного старта сходились к ложным минимумам с $\chi^2/\nu$ 30–120, с разведкой — к истине). **Вето:** параметр дефекта, не отличимый от нуля на $3\sigma$ (формальная погрешность), убирается, и фит повторяется (не более двух проходов). Выводятся параметры с погрешностями, $\chi^2/\nu$ до и после, RMS остатков, графики остатка, отпечатка (Δ-остаток от Ψ-остатка) и $n(\lambda)$ (при поглощении — и $k(\lambda)$ на правой оси).

**Сверка с истиной** (только для встроенных и симулированных образцов): набор дефектов, толщина, $\delta$, $d_r$, $k_{400}$, $n(550)$, фактический угол, полоса и сдвиг шкалы.

**Разбор причин отклонения** — два уровня:

1. *Правила*: дефект ниже порога обнаружения (≈0.4 %, ≈0.4 нм, ≈$2\cdot10^{-4}$ по $k_{400}$ при $\sigma_\Psi \approx 0.02°$); край поглощения материала слишком близок к порогу хвоста ($E_g < E_t + 0.8$ эВ — хвост неотличим от собственного края); классификатор не уверен (< 60 %) или недообучен (< 70 % на отложенных); истинный размер вне диапазона обучения; ИИ выбрал верно, но вето отбросило дефект; канал якорей (в том числе канал поглощения — перепад Ψ-остатка синие − красные якоря) противоречил выбору ИИ; ИИ выбрал поглощение, которого нет (затухание полос к синему краю имитируют полоса прибора и отклонение $E_0$, $C$); истинная толщина вне априорного интервала или ошибка толщины порядка периода полос (перепутан порядок интерференции); фактический угол отличается от номинала больше заявленной неопределённости (ошибка угла сдвигает линию подложки и имитирует градиент, ≈0.3 % на 0.1° при 60–65°); полоса в истине не совпадает с полосой генератора; задняя сторона есть в измерении, но выключена в модели (или наоборот); истинная доля задней стороны отличается от заданной больше её неопределённости.
2. *Бюджет отклонения*: тот же фит при истинном наборе дефектов повторяется на спектрах, синтезированных из истины с последовательно убираемыми искажениями — шум, дрейф, сдвиг шкалы λ, полоса, ошибка угла, доля задней стороны (если отличается от заданной), форма дисперсии ($E_0$, $C$, $E_{uv}$ как у образца). Разность соседних строк — вклад убранного фактора; остаток после всех — предел модели (дискретизация, EMA-смесь, локальный минимум). Порог «значимого» отклонения: 1.5 нм по толщине, 0.2 % по градиенту, 0.3 нм по слою, $0.3\cdot10^{-3}$ по $k_{400}$, 0.005 по $n$.

### 5.3. Поток данных

```
файл / встроенный образец / симулятор ──► S.data {lam, psi, del, sigPsi, sigDel}
                                                 │
   априорные условия ──► S.cfg, S.prior, S.nuis  │
                                                 ▼
                       шаг 1: referenceFit ──► S.ref (P, E, resid, chi2), S.refFeat
                                                 │
                       шаг 2: N × trainingExample ──► X, y ──► trainSoftmax, ridge (δ, слой, k₄₀₀) ──► S.train
                                                 │
                       шаг 3: S.train.model.predictProba(S.refFeat) ──► S.probs, S.est, флажки
                                                 │
                       шаг 4: finalFit (+ вето) ──► S.fin ──► таблица, графики
                                                 │
            если есть истина (S.example.truth) ──► сверка ──► causeAnalysis (правила + бюджет)
```

Шаг 2 выполняется порциями по ~120 мс через `setTimeout`, чтобы интерфейс не замораживался и полоса прогресса обновлялась.

## 7. Форматы файлов

### 7.1. Входной спектр

* **.xlsx / .xls** — первый лист. Строка заголовка — первая строка, где ≥ 2 текстовых ячеек; столбцы распознаются по заголовку: λ (`λ`, `lam`, `wave`, `нм`, `nm`), Ψ (`ψ`/`psi` без `σ`, `sig`, `err`), Δ (`δ`/`delta` без них), σΨ (`σψ`, `sig…psi`, `err…psi`), σΔ (`σδ`, `sig…del`, `err…del`). Без заголовка — позиционно: λ, Ψ, Δ, σΨ, σΔ.
* **.csv / .txt** — разделитель `;`, табуляция или `,` (определяется автоматически); при разделителе, отличном от запятой, десятичная запятая допускается.
* Единицы: нм и градусы. Δ приводится к [0°, 360°); строки сортируются по λ; нужно не меньше 20 строк с числами. Если столбцов σ нет — берётся значение «σΨ по умолчанию» и $\sigma_\Delta = 2\sigma_\Psi$.

Тестовые файлы `examples/*.xlsx` содержат лист «Спектр» (λ, Ψ, Δ, σΨ, σΔ) и лист «Условия» (априорная информация, которую вводит аналитик); истина — в `examples/answer_key.xlsx`.

### 7.2. Экспорт

Кнопка «Скопировать спектр как CSV»: `lambda_nm;Psi_deg;Delta_deg;sigPsi_deg;sigDelta_deg`, четыре знака после запятой. Такой файл загружается обратно как файл пользователя.

### 7.3. `examples/examples.json`

Массив объектов `{id, file, title, mat, sub, phi, dNom, dRange, bw, lam[], psi[], del[], sigPsi[], sigDel[], truth: {d, delta, dRough, phiTrue, bw, lamOffset, mat: {A, E0, C, Eg, Auv, Euv, Ak?}, n: {450, 550, 650, 750}, k400?, k?: {450, 550, 650, 750}}}`; поля `k400`, `k` и `mat.Ak` есть только у образцов с хвостом поглощения (06–08), поля `back: {f, ds, ferr}` (заданная доля, толщина в нм, неопределённость) и `truth.back: {f, ds}` (истинная доля) — только у образца 09, поэтому записи 01–08 байт в байт совпадают с предыдущими версиями. Генерируется `tools/gen_examples.js` детерминированно (зёрна 101…909).

## 9. Точность, пороги, время

* Пороги обнаружения при $\sigma_\Psi \approx 0.02°$, одном угле и мешающих факторах по умолчанию: слой шероховатости ≈ 0.35–0.4 нм, градиент ≈ 0.2–0.4 %, хвост поглощения $k_{400} \approx 1$–$3\cdot10^{-4}$ при толщине ~1 мкм (на кремнии чувствительнее, чем на стекле; порог растёт как $1/d$). Ниже — не ошибки ИИ, а предел данных.
* Точность классификатора на отложенных примерах (12 классов): 70–80 % по всем размерам (включая заведомо необнаружимые), 85–95 % выше порога при $N$ = 600–800; растёт с числом примеров.
* Формальные погрешности фита занижены: систематика угла, полосы и шкалы λ в них не входит. Ошибка угла 0.05° при 60–65° эквивалентна градиенту ≈ 0.16 %.
* Время (одно ядро): прямая задача для 42 слоёв на 201 точке — 0.8 мс, аналитический якобиан по 7 параметрам — 7 мс; опорный фит 0.02–0.2 с; обучающий пример 0.05–0.3 с; 800 примеров — 1.5–4 мин; окончательный фит с 2–4 стартами 0.01–0.5 с, с поглощением (ещё до 8 стартов раунда разведки) 0.1–0.8 с; разбор причин 1–5 с. С задней стороной подложки (матричный метод + численный якобиан) опорный фит 0.2 с, обучающий пример 0.15–0.2 с, окончательный фит 1–3 с.

## 10. Ограничения

* Один угол падения. Задняя сторона подложки моделируется только как некогерентная сумма для плоскопараллельной подложки с заданной долей; клиновидная подложка, частичная когерентность (тонкие подложки, узкая полоса) и отражение от держателя не описываются — их вклад ложится в остаток.
* Список классов закрыт: шероховатость нижней границы, анизотропия, нелинейный профиль, поглощение иной спектральной формы (полоса внутри диапазона, свободные носители в ИК) будут «втиснуты» в ближайший класс; защита — контроль $\chi^2/\nu$ после окончательного фита.
* Хвост поглощения имеет фиксированную форму (порог $E_t$ = 1.2 эВ, лоренциан материала) и один параметр; для материалов с $E_g$ ниже ≈ 2 эВ он неотличим от собственного края поглощения (свободные $A$, $E_g$ его поглощают), для широкозонных — отделяется хорошо. Затухание полос к синему краю имитируют также спектральная полоса прибора и отклонение $E_0$, $C$ от справочных — они входят в мешающие факторы обучения, но при больших отклонениях ИИ может выбрать ложное поглощение.
* Форма дисперсии фиксирована ($E_0$, $C$, $E_{uv}$ справочные); материал должен быть прозрачен или слабо поглощать в диапазоне измерения (край поглощения на синем краю допустим — свободны $A$, $E_g$).
* Классификатор привязан к конфигурации (материал, подложка, угол, интервал толщины, прибор): при их смене шаг 2 нужно повторить.
* Линейный профиль с $|\delta| > 20$ % и слои толще 12 нм не допускаются.

## 11. Разработка и тесты

```bash
npm install                  # только jsdom для дымового теста интерфейса
npm run build                # index.html из шаблона, ядра и примеров
npm test                     # сквозной прогон девяти образцов в Node, 600 примеров на образец (≈6–8 мин); node test/run_examples.js 400 ex6,ex9 — часть образцов
npm run test:ui              # дымовой тест интерфейса в jsdom (≈12–15 мин; jsdom в 3 раза медленнее браузера)
npm run verify:book          # сверка ядра с книгой Фурмана–Тихонравова, якобиан по 7 параметрам, КК хвоста поглощения, задняя сторона подложки (≈3 с)
npm run examples:check       # examples.json воспроизводится генератором без изменений
npm run examples             # перегенерировать examples.json и .xlsx (нужен python3 + openpyxl)
```

Изменять следует `src/` и `examples/examples.json`, затем пересобирать `index.html`; правки прямо в `index.html` при следующей сборке будут потеряны.
